# アマダ生産計画抽出ツール

生産計画のExcel（最大4ファイル）を読み込み、選んだ機種の定義に沿って「機種名・シリアル・JIT日」を抽出し、Excelで保存するブラウザ用ツール。
1ファイルのHTML（index.html）で完結。ExcelはSheetJS（xlsx 0.18.5）で読み書きする。

## 使い方の流れ
1. 取り込み枠にExcelをドラッグ（画面全体がドロップ先）またはクリックで選択。最大4つ。ファイル1〜4の枠にファイル名を表示（2列×2段）。
2. 機種選択（ラジオボタン、1つだけ選択）。
3. 「処理開始」を押す → 定義チェック → 抽出結果を表示 → 保存ダイアログ（ファイル名を自由に入力、保存先はブラウザの保存画面）。

## 画面仕様（変更履歴の結果）
- ノートPC向け（スマホ非対応）。タイトル〜処理開始ボタンまで1366×650程度で1画面に収める。
- 背景：花柄のシームレス画像（data URIで埋め込み、420px四方でタイル、固定）。
- タイトル：AMADAロゴ画像（透過PNG、data URI）＋「生産計画抽出」2.4rem。
- 取り込み枠：薄い緑（--drop-bg）、ドラッグ中は黄色。
- ファイル枠：実線グレー。クリックで選択（朱色・白文字）、複数選択可。
- 「ファイルクリア」：右半分の幅・右寄せ、平面、黄色背景＋黄色枠、黒太字。選択したファイルだけ削除し、残りは番号が繰り上がる（2→1）。左に赤字「ファイルを間違った場合は選択しクリア」。
- 「機種選択」見出し：朱色の帯に白太字。枠内右下に「クリア」ボタン（ラジオの選択解除）。
- 機種（2列）：左 HG / EGB制御盤 / EGB別盤 / HRB　集計 / HRB　土岐 / HRB　KD / HRB　大型 / HRB　ATC盤、右 複合機 / レーザ / AE / 発振器 / 小板発振器 / FLW / （空き）/（空き）。※HRBと名称の間は全角スペース。
- 「処理開始」：機種選択の下、全幅、グレーの立体ボタン（濃いグレー枠）。常に押せる。
- エラー表示（C案）：赤枠・薄赤背景、×アイコン付き見出し、項目ごとに白い小枠で「原因（濃い赤太字）」と「→ 対処」。右下に赤い「OK」ボタン（閉じて画面最上部へ戻る）。
  - ファイル未取り込み／機種未選択／処理未設定の機種／定義アンマッチ／取り込み・保存の失敗をこの形で表示。

## 機種ごとの処理（PROCESSORS）
各機種に validate（定義チェック）と extract（抽出）を持たせる。未登録の機種は「処理はまだ設定されていません」エラー。

### HRB　土岐（設定済み）
- 抽出：7行目以降、D列=機種名、F列=シリアル。P列以降で▲のあるセルの真上（6行目）の日付をJIT日。月は5行目の「○月」、年はファイル上部の「○年○月」から判定。
- 除外：機種名の左から3文字が「HRB」以外（NFKC正規化・大文字小文字無視・先頭空白無視）。機種名に「AESA」を含む行。
- エラー定義（いずれかに該当でエラー、該当ファイル枠を赤枠に）：
  - 項目：1〜5行目に「○年○月」がない／P列以降に▲が1つもない
  - 列：P列以降の列がない／7行目以降のD列に機種名がない／F列にシリアルがない
  - 行：6行目（P列以降）に日付がない／5行目（P列以降）に「○月」がない
- 保存：既定名「HRB土岐_JIT日一覧_YYYY年M月」、自由に変更可、.xlsx自動付与、使えない文字はチェック。

## 実行環境メモ
- 元はclaude.aiのArtifactとして公開（https://claude.ai/artifact/QtZ97JpQLMa7WV2ELPri2e）。保存は window.claude.use('downloads') を使い、無い環境では <a download> で保存する（両対応済み）。
- デスクトップ配布用は、xlsxライブラリを<script>内に埋め込み、ファビコン（icon.ico相当）を付けたオフライン版HTML（アマダ生産計画抽出.html）を作る。
- ユーザーはWindowsのデスクトップにショートカット（icon.icoを設定）を置いて起動している。修正後はオフライン版を作り直して上書きしてもらう。
